Odoo Dev URL
The app currently defaults to:

ODOO URL: http://mmatli.ddns.net:1616
Database: full_test
Site model: travel.site

To test against your local Odoo Dev server instead, start Expo like this:

$env:EXPO_PUBLIC_ODOO_URL="http://mmatli.ddns.net:1616"
$env:EXPO_PUBLIC_ODOO_DB="full_test"
$env:EXPO_PUBLIC_ODOO_SITE_MODEL="travel.site"
$env:EXPO_PUBLIC_ODOO_PROXY_URL="http://10.0.2.2:17777"

npx expo start --android --clear


Get-NetTCPConnection -State Listen -LocalPort 3000,8081,19000,19001,19002,17777 |  Select-Object -ExpandProperty OwningProcess -Unique |   ForEach-Object { Stop-Process -Id $_ -Force }
